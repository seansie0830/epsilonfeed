# 大航海時代的香料狂熱：肉荳蔻、丁香與荷蘭東印度公司在班達群島的血腥暴利

> **迷因導讀**：今天你在星巴克隨手撒在南瓜拿鐵上的肉荳蔻粉，或是廚房角落那罐快過期的滷包香料，如果穿越回十七世紀的阿姆斯特丹，大概能直接在運河邊置產買豪宅，甚至附贈一艘配備三十門火砲的武裝帆船。在那個沒有冷藏庫、黑死病隨時敲門的荒唐年代，歐洲貴族為了一顆長在地球另一端火山小島上的黑褐色堅果搶到傾家蕩產。而人類史上第一家跨國股份制「暴利天團」荷蘭東印度公司（VOC），更是為了把控這百分之六萬的毛利率，直接在東印度群島上演了一場滅絕整座島嶼原住民的商業大屠殺。現代金融資本主義的產房裡，漂浮的可不是什麼溫情脈脈的自由貿易奶香，而是浸泡在肉荳蔻精油與火藥味中的淋漓鮮血。

## 一、 舌尖上的黃金：中世紀歐洲對香料的宗教式崇拜

現代打工人很難想像，人類文明史上最龐大的全球航海大冒險、數萬水手的壞血病地獄，以及無數次海戰炮擊的起點，竟然是為了滿足舌尖上的微小刺激。

在中世紀晚期至文藝復興時期的歐洲，香料（尤其是肉荳蔻 Nutmeg、肉荳蔻皮 Mace、丁香 Clove、黑胡椒）根本不是調味品，而是集**金融貨幣、玄學醫療、身分認同與宗教神話**於一體的超級硬通貨。

```
【中世紀歐洲的香料神話閉環】
  肉類易腐臭 ───► 狂撒香料掩蓋異味 ───► 宴會頂級炫富（身分地位象徵）
       ▲                                            │
       │                                            ▼
  黑死病橫行 ◄───「瘴氣致病說」迷信 ◄─── 香料荷包避邪防疫（一顆堅果抵防毒面具）
```

### 1. 防腐神話與炫耀性消費的極致內卷
過去歷史課本常說「歐洲人需要香料是為了防腐」，這其實只說對了一半。在沒有冷凍技術的漫長冬天，貴族領主們屠宰牲畜後用粗鹽醃漬，到了初春那些牛肉早已變質發酸、纖維柴如乾柴。平民只能忍氣吞聲就著黑麵包硬吞，但有錢有爵位的封建老爺們怎麼能忍受「貧窮的酸腐氣息」？

於是，掩蓋肉類腐敗氣味並刺激味蕾的香料，成了宮廷宴席的唯一救贖。在都鐸王朝或哈布斯堡家族的奢華宴會上，菜餚煮得好不好吃是次要的，端上來的烤天鵝、烤全鹿如果沒有被一層厚厚的肉荳蔻與肉桂粉覆蓋，主人的面子就徹底「破防」了。當時甚至流行把香料做成巨大的砂糖香料雕塑擺在桌子中央，宴席結束後像分金條一樣賞賜給心腹。這不是吃菜，這是把液態黃金直接塗在嘴唇上給賓客舔。

### 2. 黑死病防護玄學：肉荳蔻成了中世紀的 N95 口罩
如果說貴族炫富只是擴大了香料的日常需求，那麼 14 世紀中葉橫掃歐洲的黑死病（鼠疫），則直接將肉荳蔻推上了「神壇」。當時歐洲醫學界普遍深信「瘴氣理論（Miasma Theory）」，認為鼠疫是空氣中腐爛骯髒的惡性氣體通過毛孔鑽入人體導致的。

當時的頂流名醫開出的「避疫方」，就是隨身佩戴裝滿肉荳蔻、丁香與樟腦的香球（Pomander），走在路上隨時拿起來猛吸一口；倫敦與巴黎的有錢人甚至相信，把肉荳蔻磨碎塗在腋下淋巴結處，就能形成一層百毒不入的「神聖靈氣護甲」。這種迷信導致肉荳蔻在倫敦大瘟疫期間價格暴漲十數倍，一顆小小的乾癟堅果，市價一度等同於三頭健壯的耕牛，或者一名熟練工匠整整五年的薪水！

### 3. 陸上商路的千倍剝削：威尼斯與鄂圖曼的「過路費抽乾術」
但在大航海時代之前，歐洲人根本不知道香料究竟從哪裡來。阿拉伯商人把產地編造成神話故事：有人說肉荳蔻長在由劇毒飛蛇看守的伊甸園懸崖上，必須用特製長矛挑下來；有人說丁香是生長在地獄邊緣的神秘灌木。

在現實的貿易鏈條中，產自東南亞的香料必須經過極度繁複的倒手轉運：
1. 馬來水手將香料從摩鹿加群島運到馬六甲海峽；
2. 印度與阿拉伯商人接盤，橫渡印度洋運往波斯灣或紅海；
3. 埃及馬木路克蘇丹國（後為鄂圖曼帝國）徵收高達 30%～50% 的過路關稅；
4. 最終在亞歷山大港或貝魯特，由威尼斯共和國的商人買下，裝船運抵歐洲分銷。

經過這七八層中間商的層層課金與盤剝，當一磅肉荳蔻抵達阿姆斯特丹或倫敦時，其價格已經比產地翻了整整 **1,000 到 2,000 倍**！全歐洲的白銀像開了閘的洪水一樣流向地中海東岸，讓西歐新興君主與大商人看得眼珠發紅、咬牙切齒：「既然陸路被鄂圖曼土匪和威尼斯奸商把持，那我們就造大船，繞過好望角，直接去地球的盡頭搶源頭！」

## 二、 全球首家股份制掠奪機器：荷蘭東印度公司（VOC）的商業殘酷

西元 1602 年，剛從西班牙統治下獨立不久的荷蘭聯省共和國，幹了一件改變人類經濟史的大事：將數家互相削價競爭的遠洋貿易商行合併，成立了**荷蘭東印度公司（Vereenigde Oostindische Compagnie，簡稱 VOC）**。

這家公司不僅是人類史上第一個發行公開流通股票、擁有董事會與有限責任制度的現代現代跨國企業，更可怕的是，荷蘭國會賦予了它幾乎等同於國家主權的特權：**它可以自建武裝海軍、鑄造專屬貨幣、在海外築城設防、擅自對外宣戰與簽訂條約，甚至擁有宣判海外居民死刑的司法審判權**。這根本不是一家單純的進出口貿易公司，而是一個披著股份制外衣、以追逐極致利潤為唯一神祇的武裝殖民怪物。

```
【VOC 暴力定價模型（極致壟斷方程式）】
  利潤極大化 Max(Π) = 限制供應量 (Q ↓) × 摧毀競品替代 (Sub = 0) × 全球暴利定價 (P ↑↑↑)
  手段：武裝清剿走私 + 拔除他島樹苗 + 種族屠殺更換無償奴隸勞工
```

### 1. 班達群島：上帝地理大富翁裡的唯一孤品
VOC 的目光，死死鎖定在了印尼東部班達海上的幾座微型火山島——**班達群島（Banda Islands）**。

在十七世紀初，這片總陸地面積加起來甚至不如今天半個台北市的小島群（最大島嶼大班達島僅約 40 平方公里），是**全世界唯一出產肉荳蔻（Nutmeg）與肉荳蔻皮（Mace）的地方**！因為肉荳蔻樹對生長環境極度挑剔：需要終年潮濕高溫的熱帶雨林氣候、極度肥沃的富鐵火山灰土壤，以及極佳的排水坡度。全地球七大洲，偏偏只有班達群島的群山完美契合這項條件。

只要誰能徹底控制班達群島，誰就握住了全球肉荳蔻供應的絕對水龍頭。VOC 董事會（著名的「十七紳士」，Heeren XVII）下達的密令極其冷酷：「不計一切代價，徹底切斷其他所有國家獲取肉荳蔻的可能，建立百分之百的絕對獨占。」

### 2. 令人倒吸一口涼氣的暴利對比：60,000% 的毛利率神話
為了讓大家理解當時這筆買賣有多誇張，我們依據荷蘭海牙國家檔案館（Nationaal Archief）的 VOC 貨物清單與拍賣紀錄，整理出 17 世紀中葉肉荳蔻從樹上摘下到歐洲貴族餐桌的驚天價格躍升：

| **區域集散** | 巴達維亞（今雅加達，VOC 亞洲總督府） | **0.08 ～ 0.12 盾**（包含東印度境內水運損耗） | 10 ～ 20 倍 | 扣除武裝艦隊巡邏成本 |

### 3. 資本主義的控盤術：寧可燒掉，絕不降價！
現代人常嘲諷「資本家寧可把牛奶倒進水溝也不給窮人喝」，而這套劇本早在 400 年前就被 VOC 玩到了爐火純青的境界。

為了維持肉荳蔻在歐洲每磅 3 荷蘭盾以上的「奢侈品神位」，VOC 每年嚴密計算歐洲市場的吞吐極限。當遇到豐收年、產量過剩時，VOC 不會降價促銷，而是採取兩種極端手段：
* **海上火祭**：直接將成百上千噸剛運抵阿姆斯特丹的肉荳蔻倒在碼頭邊，當著全城居民的面點起熊熊大火。據當時文獻記載，整個阿姆斯特丹港口整整三天三夜瀰漫著濃烈的辛香，海面上漂滿了燃燒的堅果油脂，圍觀的破產市民只能望洋興嘆。
* **滅絕式拔樹（Extirpation）**：VOC 組建了全副武裝的巡邏小艇部隊，每年定期在摩鹿加群島的數千座無人島或非核心控制島嶼巡航。只要發現野生或原住民私種的肉荳蔻樹與丁香樹，一律放火焚毀、連根拔除，違法種植者全家處死。VOC 硬生生用鋼刀與火把，在整個南太平洋製造出了一座人為的「生態荒漠」，只為確保產量僅限於自己重兵把守的班達群島。

## 三、 1621 年班達群島大屠殺與曼哈頓島交換的歷史反諷

當極致的商業利潤不需要受任何道德與法律約束時，等待原住民的必然是滅頂之災。班達群島的悲劇，是現代殖民史上最黑暗也最赤裸裸的種族滅絕罪行之一。

```
【1621 班達群島血腥清洗與人口替代】
  原本島民：約 15,000 人（自主農民、海洋貿易者）
        │
        ▼ 揚·庫恩發動屠殺、斬首、誘捕、流放
  浩劫殘存：不到 1,000 人（淪為採摘奴隸）
        │
        ▼ 導入奴隸莊園制（Perkenier 制度）
  人口重組：荷蘭莊園主（Perkeniers）+ 爪哇/非洲奴隸大軍
```

### 1. 屠夫總督揚·庫恩（Jan Pieterszoon Coen）的冷血屠刀
原本的班達群島由當地的長老會議（Orang Kaya）治理，世代與爪哇、阿拉伯、馬來甚至中國商人自由交易。當 VOC 到達後，強迫長老們簽署一份他們根本看不懂的荷蘭語合約，要求他們「永遠只能以極低固定價格將所有肉荳蔻賣給荷蘭人，否則視為叛國」。

班達人很快發現，荷蘭人給的價格根本買不起足夠維持全島生存的糧食（班達群島全種香料，糧食仰賴進口），於是私下將一部分肉荳蔻偷偷賣給出價合理十倍的英國商人與爪哇商人。

這徹底激怒了時任 VOC 亞洲總督**揚·彼得斯佐恩·庫恩（Jan Pieterszoon Coen）**。這位歷史上臭名昭著的「鐵血總督」信奉一句座右銘：*「沒有貿易就沒有戰爭，沒有戰爭就沒有貿易（Dispereert niet, ontziet uwe vijanden niet, want God is met ons）」*。

1621 年 3 月，庫恩親率 19 艘戰艦、1,655 名荷蘭士兵以及數十名受雇於 VOC 的日本浪人武士（傭兵），強行登陸班達群島：
* **誘殺長老**：庫恩藉口談判，誘騙了班達群島最有威望的 44 位部族長老走進談判帳篷，隨後日本武士一擁而上，將這 44 位長老當場全部斬首、肢解，頭顱被插在竹竿上示眾。
* **全面種族滅絕**：隨後，荷蘭部隊在群島展開地毯式清洗。村莊被燒毀，農田被投毒，島民被驅趕進死火山深處活活餓死，或在懸崖邊被逼投海自盡。成千上萬的婦女兒童被當作牲畜裝上運奴船，送往巴達維亞的奴隸市場。

**屠殺成果的冰冷數字**：
在大屠殺前，班達群島的人口估計在 **15,000 至 16,000 人**左右；到了 1621 年底，島上原住民只剩下不到 **1,000 人**。庫恩總督用幾個月的時間，徹底抹殺了一個人數上萬、延續千年的古老民族。

隨後，庫恩將全島劃分為 68 個名為「Perken」的種植莊園，分封給 VOC 退伍軍官（稱為 Perkenier），並從爪哇島、新幾內亞甚至非洲大量運來黑奴，在荷蘭督工的皮鞭下日夜採摘肉荳蔻。自此，VOC 徹底建立起「零工資成本、純暴力維穩」的肉荳蔻血腥壟斷體系。

### 2. 嵐島（Run Island）之圍與世紀大換購：拿曼哈頓換一顆堅果！
然而，在班達群島這串明珠中，還剩下一根讓荷蘭人如鯁在喉的肉刺——**嵐島（Run Island）**。

嵐島是班達群島中最西端、最小的一個孤懸珊瑚島，長僅 3 公里，寬不到 1 公里。1616 年，英國東印度公司（EIC）的冒險家納撒尼爾·考特霍普（Nathaniel Courthope）率領兩艘武裝商船登上嵐島，與絕望中的當地人結盟，宣布該島臣服於英王詹姆士一世。這使得嵐島成為**大英帝國歷史上第一個真正意義上的海外殖民地**！

```
【1667 年《布雷達合約》的世紀地產大置換】
  英國（EIC）                 荷蘭（VOC）
  放棄：嵐島（Run Island）   ──► 獲得：班達群島最後拼圖（全球肉荳蔻 100% 絕對獨占）
  獲得：新阿姆斯特丹（紐約曼哈頓） ◄── 放棄：北美寒冷皮草小哨站
```

荷蘭人對這座插著英國國旗的小島發動了長達四年半的海上圍困與瘋狂炮擊。考特霍普帶領島民與水手在島上硬生生用椰子樹築壘死守，直到他最終中彈落海陣亡。這座微型小島引發了英荷兩國之間爆發長達數十年的兩次英荷戰爭。

到了 1667 年，歷經第二次英荷海戰重創的英國與荷蘭坐在談判桌前，簽署了著名的**《布雷達合約（Treaty of Breda）》**。在合約中，雙方做出了一個在今天看來宛如瘋狂喜劇的領土交換：

* **英國決定放棄**：位於東印度的肉荳蔻聖地「嵐島」，徹底承認荷蘭對班達群島所有肉荳蔻資源的絕對專屬統治；
* **荷蘭決定割讓**：位於北美洲東海岸、在當時看來只是一片氣候泥濘寒冷、僅能收購幾張河狸皮毛的荒涼貿易站——**新阿姆斯特丹（New Amsterdam）**。

英國人接手新阿姆斯特丹後，為了紀念約克公爵（後來的英王詹姆士二世），將這片土地重新命名為：**新約克（New York，紐約）**；而那個被荷蘭人用來交換的曼哈頓島（Manhattan Island），如今成了全球資本主義的心臟與摩天大樓林立的世界金融中心。

荷蘭人當時歡欣鼓舞，阿姆斯特丹股市開香檳慶祝，認為自己用一塊「毫無前途的北美泥巴地」換來了「全球唯一且永遠壟斷的印鈔機」。然而歷史跟荷蘭人開了一個長達數百年的黑色幽默：
18 世紀末，法國傳教士兼植物學家皮埃爾·波微（Pierre Poivre）冒死潛入摩鹿加群島，將肉荳蔻與丁香樹苗偷渡出境，成功移植至法屬模里西斯與留尼旺島；隨後英國人又在檳城、新加坡與加勒比海的格瑞那達成功大面積種植。

肉荳蔻的神話瞬間破滅，價格一瀉千里。當肉荳蔻從每磅數百荷蘭盾暴跌成普通人廚房裡的隨手香料時，曼哈頓島的地價卻正在以幾何級數飆升。這場被後世經濟學家稱為「人類史上最虧本的土地併購案」，成了 VOC 與荷蘭帝國盛極而衰的鮮明註腳。

## 四、 結語：每一顆浸透血腥的香料種子，都刻著現代資本主義最初的罪惡基因

馬克思在《資本論》中有一段流傳百年的經典判詞：
> *「資本來到世間，從頭到腳，每個毛孔都滴著血和骯髒的東西。」*

如果說英國的工業革命是把棉紡織機架設在圈地運動流離失所的農民骨骼上，那麼荷蘭東印度公司的商業繁榮，則是把現代金融體系的奠基石，深埋在班達群島一萬五千名原住民的焦黑骨灰之中。

今天我們走進現代金融市場，開口閉口是「有限責任公司」、「公開招股上市（IPO）」、「期貨避險合約」、「中央銀行跨國結算」。我們驚嘆於阿姆斯特丹證券交易所的精巧設計，讚美荷蘭黃金時代留下的倫勃朗油畫與優雅的紳士運河。但歷史的聚光燈往往刻意避開了熱帶雨林深處的罪惡：
* 正是班達群島上那高達 60,000% 的肉荳蔻暴利，為阿姆斯特丹提供了源源不絕的原始資本積累；
* 正是武裝艦隊對海外航路的殘暴封鎖，為 VOC 的股票持有者們帶來了連續數十年超過 20% 的天量現金分紅；
* 正是人類歷史上第一次將「軍隊、國家主權、跨國法人、暴利追逐」合體變異，才誕生了日後席捲全球、無往不利的現代帝國主義擴張範式。

下次當你在早午餐店拿起調味罐，漫不經心地在熱可可或法式吐司上輕輕灑上一層肉荳蔻粉時，不妨停下來看一眼這細膩如沙的棕褐色微粒。它所散發出的溫暖甜香底下，曾經燃燒過整座火山島嶼的烈火，航行過無數幽靈般的武裝蓋倫帆船，更記錄著人類為了貪婪與金錢，所能展現出的最極致的優雅智慧與最純粹的野蠻殘酷。
