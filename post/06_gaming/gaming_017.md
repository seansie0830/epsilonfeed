# 遊戲 UI/UX 與注意力經濟：眼動追蹤、小地圖視覺疲勞與沉浸式無介面 Diegetic UI

> **迷因導讀**：3A 大廠花費了整整五億美元的預算、動用六百名頂級美術工程師、利用次世代虛幻引擎 5 刻畫出樹皮毛孔都看得一清二楚的奇幻開放世界。然而當使用者體驗（UX）研究室把眼動追蹤儀（Eye-Tracking）套在受試玩家頭上時，所有專案經理與美術總監當場心肌梗塞集體破防——熱區圖（Heatmap）無情地顯示：玩家整整 80% 的視線時間，死死黏在螢幕邊緣直徑不到兩公分的小圓圈「雷達小地圖」和左上角那根螢光綠的血條上。玩家們在社群上發自靈魂深處地吐槽：「我這哪是在海拉魯或諾維格瑞探索奇幻史詩？我這分明是在尖峰時段下班開著國道一號盯著 Google Maps 導航跑外送吧！」當現代遊戲美術逼真到足以乱真，人類的 UI 設計卻悲劇性地把次世代沉浸體驗打回成了「打地鼠式的雷達盲人摸象」。本篇專題我們將徹底撕開遊戲介面背後的注意力經濟黑箱，從眼動視覺生理學、四維介面分類法到極致的無介面（Diegetic）設計，帶你一探科技如何讓我們忘記螢幕，直面靈魂的共振。

## 一、 視覺注意力的通道瓶頸：從 F 型掃描到小地圖依賴症

在探討為什麼當代 3A 開放世界大作總是不知不覺淪為「電子導航模擬器」之前，我們必須先從人類極度「偏心」且帶有嚴重演化缺陷的視覺硬體系統談起。

### 1. 2度的殘酷現實：中央凹（Fovea Centralis）的窄頻寬悲劇
現代遊戲顯示器已經動輒邁向 4K 144Hz 甚至是超寬曲面 OLED 螢幕，視野（FOV）拉滿到 110 度以上，光影粒子效果極盡奢華之能事。然而，人類大腦接收這座視覺金礦的硬體天花板，卻被生物構造卡得死死的——**人類視網膜的「中央凹」（Fovea Centralis）高解析度有效視覺夾角僅有可憐的 1 度到 2 度**。

這是什麼概念？伸直你的手臂，豎起你的大拇指，指甲蓋大小的範圍就是你大腦唯一能清晰分辨文字、高頻細節與色彩對比的「超清視訊窗口」。超出這個 2 度半徑之外的周邊視野（Peripheral Vision），大腦接收到的基本上就是高度壓縮、低解析度、對色彩極度遲鈍、僅對「動態物體與亮度劇變」保有防禦性敏感的模糊雜訊。

當遊戲介面設計師在 27 吋或 32 吋螢幕的四個角落，分別擺上：
- 右上角：旋轉式雷達小地圖（Minimap）
- 左上角：血條（HP）、魔力值（MP）、耐力值（Stamina）
- 右下角：彈藥計數、技能冷卻倒數（Skill Cooldown）
- 畫面正中央頂部：帶有距離刻度與圖標的指南針（Compass Bar）

這意味著，玩家的大腦必須強迫眼球進行劇烈的高頻「跳視」（Saccades）。眼球在螢幕中心（角色本體與戰鬥目標）與四角 UI 之間不斷來回梭巡。根據眼動追蹤實驗，一次典型的眼球跳視耗時約 20 到 40 毫秒，隨後的視覺注視（Fixation）則需停留 150 到 300 毫秒。如果在高強度的 BOSS 戰或高速開車場景中，玩家每秒鐘都在經歷這種眼球拉扯，其眼外肌的疲勞指數與大腦神經元消耗將呈指數級飆升。

```
【傳統 HUD 視覺跳視困境】
[ 左上: 血條/藍條 ] <===================> [ 右上: 雷達小地圖 ]
         ^                                        ^
          \           【螢幕中央】               /
           \     [ 戰鬥動作 / 奇幻風景 ]       /
            \         (2度清晰視角)          /
             v                              v
[ 左下: 任務日誌 ] <===================> [ 右下: 彈藥/技能CD ]
```

### 2. 認知負荷理論（Cognitive Load Theory）與工作記憶枯竭
眼球的物理疲勞還只是前菜，真正的致命傷在於認知架構的崩潰。認知心理學中的**認知負荷理論（Sweller, 1988）**將人類大腦處理資訊的負荷分為三類：
1. **內在負荷（Intrinsic Load）**：理解遊戲規則、判斷敵方攻擊前搖與連招時機所需的必要思考。
2. **無關負荷（Extraneous Load）**：因糟糕的資訊呈現方式而浪費在解碼、查找、眼球跳視上的多餘心智損耗。
3. **相關負荷（Germane Load）**：玩家將當前經驗內化為遊戲心流、技巧進階與情感共鳴的有益負荷。

當一款遊戲採用了密密麻麻的「非敘事層（Non-diegetic）懸浮 HUD」時，玩家短暫的「工作記憶」（Working Memory）瞬間被「無關負荷」塞爆。大腦必須在一毫秒內處理雙重現實：
- **情境 A（虛擬世界）**：眼前有一隻張著血盆大口的惡龍正在俯衝。
- **情境 B（介面資料庫）**：右上角雷達地圖上有一個閃爍的紅色骷髏標記，正上方指南針顯示寶箱在 32 公尺外，左下角字體顯示「冷卻時間剩餘 3.2 秒」。

人類的工作記憶容量極其有限（經典的米勒法則指出僅有 7±2 個資訊塊，現代認知科學更傾向於只有 4 個）。面對過載的多重資訊，大腦演化出的本能防禦機制就是**「認知節能偏好」（Cognitive Miser）**——尋找最簡單、抽象化程度最高、容錯率最高的資訊路徑。

### 3. 小地圖如何淪為剝奪世界美感的「數位盲杖」
這就解釋了為什麼小地圖會成為開放世界的「靈魂殺手」。
在立體且充滿高頻細節的 3D 遊戲世界中，要藉由觀察地形、地標、陽光方位來判斷前進路線，需要耗費大量的立體空間感知運算；反之，看右上角的 2D 小地圖，大腦只需要執行最原始的「讓箭頭貼著白線跑」的二維向量匹配。

於是，無數玩家陷入了一種病態的「小地圖依賴症」：大腦自動過濾掉了眼前耗資數千萬美元打造的逼真植被、動態體積雲與次表面散射角色模型，將其視為「背景噪音」；眼光聚焦於小地圖上那個由幾個像素點構成的幾何指標。玩家失去了對虛擬世界的空間建構能力，原本波瀾壯闊的史詩冒險，在神經層面上退化成了「開車導航」與「雷達清點」的重複性流水線勞動。

## 二、 遊戲介面哲學全景橫評

為了解決這場介面引發的「注意力危機」，遊戲學界與人機互動（HCI）領域建立了一套極為經典的分類體系。1990 年代起，包括 Erik Fagerholt 與 Magnus Lorentzon 在《Beyond the HUD》研究中提出的四象限介面哲學，成為現代遊戲 UI/UX 設計師的最高指導綱領。

這個體系的核心維度在於兩個問題：
1. **敘事維度（Story Dimension）**：該介面是否存在於遊戲角色所處的虛擬故事世界中？角色的眼睛看得到它嗎？
2. **空間維度（Spatial Dimension）**：該介面是渲染在三維立體遊戲空間裡（附著於物體），還是扁平地貼在玩家眼前的 2D 螢幕玻璃上？

依此劃分的四大介面形態，在沉浸感、資訊響應度與認知成本上展現出截然不同的博弈特徵：

### 深度剖析：這不是美學問題，而是認知帶寬的殘酷妥協
- **Non-diegetic 的不可替代性**：在注重高頻競技與極致反饋的電競遊戲（如《星海爭霸》、《CS2》、《Dota 2》）中，追求 Diegetic 往往是災難性的。競技玩家需要的是精確到小數點後一位的數字、毫秒級更新的冷卻進度與無死角的小地圖情報。在此情境下，任何為了「沉浸感」而讓字體隨風搖曳或受物理光影遮擋的設計，都是對玩家競技生命的背刺。
- **Diegetic 的藝術神格化**：然而在以氛圍渲染、恐怖驚悚、沉浸式角色扮演為核心的敘事型遊戲中，Non-diegetic 介面就是那隻硬生生把你從夢境拉回現實的冰冷機械手。當你正被古老神廟的宏偉震撼得熱淚盈眶時，畫面上跳出一個黃色發光的「【E】搜刮屍體」矩形框，整個敘事構築的第四面牆瞬間瓦解得無影無蹤。

## 三、 無介面（Diegetic）設計的極致探索

近年來，全球頂尖敘事遊戲工作室吹起了一股向「無介面設計（Diegetic & Invisible UI）」回歸的文藝復興浪潮。設計師們不再把玩家當成需要保姆式餵飯的嬰兒，而是巧妙運用人類的直覺心理學、環境線索以及動態感知技術，讓 UI 徹底消融在世界之中。

### 1. 《對馬戰鬼》：讓天地萬物成為你的羅盤
在傳統開放世界遊戲中，前往一個任務地點通常意味著：打開選單、釘選圖標、關閉選單、盯著螢幕頂端的黃色點點或小地圖奔跑。

Sucker Punch 工作室在《對馬戰鬼》（*Ghost of Tsushima*）中給出了一個震驚遊戲業界的神級解答——**引導之風（Guiding Wind）**。

```
【引導之風（Guiding Wind）互動邏輯】
玩家輕撫觸控板 ──> 喚起物理引擎全域風力場
                          │
       ┌──────────────────┴──────────────────┐
       ▼                                     ▼
環境粒子層面：                            植被動畫層面：
落葉、花瓣、灰燼隨風激盪                   整片芒草原、竹林逆向倒伏
       │                                     │
       └──────────────────┬──────────────────┘
                          ▼
             【玩家視線始終停留在世界正中央】
             (直覺感知方位，完全剔除 2D UI 疊層)
```

設計團隊在遊戲中徹底砍掉了傳統的指南針小地圖。當玩家需要指引時，只要手指在 PS 手把的觸控板上輕輕一劃，整個虛擬世界的物理引擎隨之響應：
- 遠方漫天飛舞的金黃色銀杏落葉或櫻花花瓣，會朝著目標方向優雅呼嘯。
- 角色身旁半人高的芒草海與竹林，會順著風向翻湧起層層浪濤。
- 甚至連天空的動態體積雲與狼煙，都在無聲地訴說著地理空間的秘密。

不僅如此，尋找隱秘的神社靠的是跟隨靈動跳躍的**黃金鳥（Golden Birds）**與飛舞的**指路狐狸（Inari Foxes）**；探索溫泉靠的是遠處蒸騰升起的白霧；尋找敵營靠的是盤旋在天際的黑色烏鴉與盤旋黑煙。
這種設計在眼動追蹤測試中展現了近乎奇蹟的數據：玩家的視覺焦點始終保持在畫面中央 1/3 的美麗風景之中，視網膜周邊視覺被自然現象溫和喚醒，大腦的認知負荷從「處理人造符號」轉化為「閱讀自然環境」，沉浸感由此封神。

### 2. 《荒野大鏢客：救贖 2》：極致動態 HUD 與環境聲學的心理暗示
Rockstar Games 在《荒野大鏢客：救贖 2》（*Red Dead Redemption 2*）中，則展現了一套教科書級別的「動態閾值（Dynamic HUD Thresholding）」架構。

R星深知，強行完全拿掉 UI 會讓休閒玩家陷入挫折感，因此他們構建了一套精密的動態露出邏輯：
- **動態隱藏原則**：在玩家騎馬慢步、策馬奔馳於雪山或林間時，螢幕上**零 UI**，乾淨得如同一部 70 毫米膠捲拍攝的西部史詩電影。
- **情境觸發機制**：只有當玩家進入拔槍瞄準狀態時，右下角才會如幽靈般浮現極簡的彈藥與左輪轉輪狀態；只有當亞瑟·摩根（Arthur Morgan）的體力因劇烈狂奔跌破 20% 安全線時，核心狀態環才會伴隨著急促的心跳聲淡入提示。
- **聲學替代光學（Audio Over Visual）**：在傳統遊戲中，敵人接近通常依靠小地圖上的紅點雷達。而《荒野大鏢客 2》引入了頂級的三維空間音訊（Spatial Audio）。當玩家在茂密的灌木叢中前行，狼群的低吼、響尾蛇在乾燥岩石上的尾巴震顫聲、賞金獵人馬蹄踩在碎石上的聲響，精確到可以藉由雙耳時間差（ITD）與雙耳強度差（IID）被大腦聽覺皮層瞬間定位。

大腦被逼退回最原始的獵人狀態——你的眼睛不再依賴螢幕角落的彩色像素圖標，你的耳朵在傾聽風吹草動，你的神經系統與荒野中的亞瑟·摩根達成了一場超越物理介質的量子糾纏。

### 3. 《絕命異次元》：敘事介面（Diegetic UI）的殿堂級標竿
如果不提 Visceral Games 打造的《絕命異次元》（*Dead Space*），任何關於遊戲 UI 的探討都是不完整的。這款 2008 年誕生的恐怖生存經典，至今仍是人機互動設計界難以企及的珠穆朗瑪峰。

主角艾薩克·克拉克（Isaac Clarke）是一名工程師，他身穿厚重的採礦太空防護服（RIG）：
- **生命值（HP）**：直接被設計成防護服背部**脊椎骨結構上的螢光霓虹管**。當生命垂危時，霓虹管逐節熄滅並由藍轉紅。
- **靜滯能量（Stasis）**：位於右肩胛骨旁的半圓形儀表。
- **彈藥顯示**：直接由武器槍身上投射出極小範圍的全息微光投影，僅在舉槍瞄準時亮起。
- **庫存與地圖選單**：不是暫停遊戲切換到二維全螢幕，而是艾薩克從胸甲前方啟動一個實時渲染的三維立體投影。當玩家查看物品欄時，**遊戲世界從未暫停**，艾薩克的眼球會隨著選單項目的切換而上下轉動，而一隻死靈變異體（Necromorph）隨時可能從陰影中撲向他的脖子。

## 四、 結語：最好的介面是隱形的，它讓玩家忘記技術的存在，直面心靈的震撼

在數位互動設計的漫長演進史中，技術的發展往往呈現一種奇妙的螺旋形上升：
起初，因為算力極度貧瘠，我們只能用滿螢幕的冷酷數值與二維文字來向玩家傳達抽象的狀態；
後來，隨著 GPU 算力爆炸，我們用越來越華麗的漸層色、粒子特效與精緻圖標把螢幕的邊邊角角塞得琳瑯滿目，自以為賦予了玩家掌控一切的神級視角；
然而到了今天，當算力與光影已經足以重新描摹一整個宇宙時，最頂級的設計師們卻開始集體做減法。

> **「完美的設計，不是在無可增添的時候，而是在無可刪減的時候。」** —— 安東尼·聖修伯里

未來的遊戲 UI 絕不會是那套遮擋住 30% 視野、把玩家馴化為雷達奴隸的非敘事 HUD。未來的交互，是微風吹動芒草時的沙沙聲，是武器過熱時金屬散發出的橘紅色暗芒，是角色在極度恐懼時劇烈的心跳與粗重的喘息，是透過環境本身與人類深層本能進行的無聲對話。

最好的介面是隱形的。它像空氣一樣無處不在，卻又從不跳出來宣示自己的主權。它褪去了一切傲慢的技術包裝，消融於虛擬世界的每一縷微光之中，最終讓螢幕前的玩家忘記了搖桿、忘記了代碼、忘記了那塊發光的液晶玻璃——在那個瞬間，靈魂穿透了維度的隔閡，與那個浩瀚世界中激盪的心靈，達成了最純粹、最極致的震撼共鳴。
